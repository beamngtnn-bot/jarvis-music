Jarvis Music

A private desktop tool for publishing original AI-assisted music to my own YouTube channel.

What it does

  • Creates original songs and music videos on my own computer (AI-assisted, clearly labeled as such).
  • Uploads the videos to my own YouTube channel using the YouTube Data API v3.
  • Reads basic statistics of my own channel to send me a private daily summary.

The tool is used only by the channel owner. It has no public users and does not access anyone else's data.
