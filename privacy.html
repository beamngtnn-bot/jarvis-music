Privacy Policy

Jarvis Music · Last updated: November 10, 2026

Who uses this application

Jarvis Music is a private desktop application used only by its developer (the owner of the YouTube channel it publishes to). It is not offered to the public.

Data we access

With the owner's permission (Google OAuth), the application uses the YouTube Data API to:

  • upload videos to the owner's own YouTube channel (youtube.upload);
  • read basic statistics of the owner's own channel and videos (youtube.readonly).

The application does not access, collect or process data of any other YouTube users.

How data is stored

OAuth tokens and channel statistics are stored only locally on the owner's computer. No data is sold, shared with third parties, or sent to any server other than Google's own APIs (and a private Telegram message to the owner containing a summary of the owner's own channel).

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Local data can be deleted by removing the application's files.

This application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
